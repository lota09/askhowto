# 죽었을 때 (쓰러졌을 때) 병원비
쓰러지면(죽으면) 누군가 구조해서 선릿 밸리 병원으로 옮겨 줍니다.
- 처음 쓰러졌을 때는 병원비 없이 무료로 치료해 줍니다.
- 두 번째부터는 치료비(병원비)를 청구하고, 은행 계좌에서 자동으로 빠져나갑니다.
- 계좌에 돈이 부족하면 남은 병원비는 은행에 빚(미납금)으로 남습니다.
- 빚이 있으면 배송 상자 판매 대금에서 미납 병원비를 먼저 자동으로 차감합니다.
- 응급 처치 안내서: 죽었을 때 병원비 최대치가 절반으로 줄어듭니다.
- 부채 그 첫 5000 동굴: 해골 광산에서 쓰러졌을 때는 병원비가 청구되지 않습니다.
